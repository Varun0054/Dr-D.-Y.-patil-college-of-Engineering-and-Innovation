## 🚀 Getting Started

### Prerequisites
```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter openpyxl
```

### Run Notebooks
```bash
git clone https://github.com/Varun0054/Dr-D.-Y.-patil-college-of-Engineering-and-Innovation.git
cd Dr-D.-Y.-patil-college-of-Engineering-and-Innovation
jupyter notebook
```

Then navigate to either the `DMV/` or `ML/` folder and open any `.ipynb` file.
